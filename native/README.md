# Stagetimer native app (iPhone + iPad)

Capacitor shell around the web app (BOUWPLAN phase 6). The app **bundles**
`../app.html` (no `server.url`), so it starts offline. There is no bundler: a
copy script puts `app.html` and the files it references into `www/`, and
`cap sync` copies that into the Xcode project.

- Bundle ID `nl.stagetimer.booth` (team `CM737LH9GZ`, automatic signing). This
  ships as an update of the existing iPad app *Stagetimer Booth*, so it is
  universal (iPhone + iPad) and the iPad keeps all orientations.
- Capacitor 8.5.3, iOS only for now, Swift Package Manager (no CocoaPods).
  Minimum iOS 16.4.
- Not deployed: `native/` is in the root `.vercelignore`.

> ## WARNING: never run a release build to test
> `app.html` hardcodes the **production** Supabase project. A build made with
> `npm run sync` (no backend flag) talks to real customer data. Use it only to
> archive for TestFlight/App Store. For the simulator, a device or any testing,
> always use `npm run sync:dev` with a local backend. `npm run ios:build-sim`
> refuses to build when the bundled `index.html` still contains production.

## Requirements

Node 20+, Xcode 16+ (tested with Xcode 26.3). No CocoaPods.

```bash
cd native
npm install
```

## Sync the web app

```bash
npm run sync:dev                                   # dev backend http://127.0.0.1:54350
npm run sync:dev -- --backend http://localhost:9   # any other local backend
BACKEND=http://192.168.1.20:54350 npm run sync:dev # e.g. a Mac on the LAN, for a real device
npm run sync                                       # RELEASE: production backend
```

`scripts/sync-web.mjs`:

- copies `../app.html` to `www/index.html`, plus `vendor/`, `fonts/` and every
  local file `app.html` references (icons, wordmark, logo, `manifest.json` and
  its icons). A referenced file that does not exist fails the sync;
- never copies `sw.js` / `OneSignalSDKWorker.js` (no service worker in the app);
- with `--backend <origin>` (or `--dev`): replaces `const SUPA_URL='https://bamjpsquhdzxvsymldpq.supabase.co'`
  (must match exactly once) and every other occurrence of that host (preconnect
  hints, the early share-link fetch in `<head>`) in the **copy**, then fails if
  the production host still appears anywhere. `app.html` itself is never changed;
- with `--cap-sync` (the npm scripts pass it): runs `cap sync ios` afterwards.

`www/` is gitignored. Re-run the sync after every change to `app.html`.

## Build and run in the simulator

```bash
npm run sync:dev -- --backend http://localhost:<port>
npm run ios:build-sim
xcrun simctl install booted build/DerivedData/Build/Products/Debug-iphonesimulator/App.app
xcrun simctl launch --console-pty booted nl.stagetimer.booth   # console.log shows as ⚡️ [log]
```

Or open `ios/App/App.xcodeproj` in Xcode and run the `App` scheme (sync first).
To debug the web view: Safari > Develop > Simulator > capacitor://localhost.

## OneSignal location module

`onesignal-cordova-plugin` pulls in `OneSignalLocation` unless the environment
variable `ONESIGNAL_DISABLE_LOCATION=true` is set **when Xcode resolves the
Swift packages**. Stagetimer does not use location, and linking it without a
location purpose string risks an App Store rejection. `ios:build-sim` sets the
flag. For an archive from the Xcode GUI, set it for GUI apps first and make
Xcode re-resolve:

```bash
launchctl setenv ONESIGNAL_DISABLE_LOCATION true   # then restart Xcode
# Xcode: File > Packages > Reset Package Caches
```

Check: the built `App.app/Frameworks` must not contain `OneSignalLocation.framework`.

## What is where

| Path | What |
|---|---|
| `capacitor.config.json` | app id/name, `webDir`, `contentInset: never` (the page handles safe areas with `env(safe-area-inset-*)`), background `#0b0b0e`, status bar light text, no splash delay |
| `scripts/sync-web.mjs` | web copy + dev backend rewrite |
| `scripts/assert-dev-build.mjs` | guard used by `ios:build-sim` |
| `ios/App/App/Info.plist` | display name, orientations, `remote-notification`, `ITSAppUsesNonExemptEncryption = NO` |
| `ios/App/App/App.entitlements` | push (`aps-environment`), `applinks:stagetimer.nl` |
| `ios/App/CapApp-SPM/Package.swift` | generated by `cap sync`, do not edit |
| `assets/` | icon source (`ios-icon.svg` = `app-icon.svg` without rounded corners) and the script that makes the 1024 PNG opaque |

## Plugins and their JS names

The web app reaches them without imports:

| Package | Runtime |
|---|---|
| `@capacitor/app` | `Capacitor.Plugins.App` |
| `@capacitor/haptics` | `Capacitor.Plugins.Haptics` |
| `@capacitor/share` | `Capacitor.Plugins.Share` |
| `@capacitor/status-bar` | `Capacitor.Plugins.StatusBar` |
| `@capacitor/splash-screen` | `Capacitor.Plugins.SplashScreen` |
| `@capacitor-community/keep-awake` | `Capacitor.Plugins.KeepAwake` |
| `onesignal-cordova-plugin` 5.6.1 | `window.plugins.OneSignal` after `deviceready` (`window.OneSignal` is the module object, use `.default`) |

Native detection: `window.Capacitor?.isNativePlatform()`.

Adding a plugin: `npm install <plugin>` then `npm run sync:dev`.
